## 1. Ключевые отличия синтаксиса (Отличия от Rust и C#)

Чтобы избежать путаницы при переходе с других языков, зафиксируем основные синтаксические особенности RustSharp:

| Аспект | В RustSharp | В Rust | В C# | Примечание |
| :--- | :--- | :--- | :--- | :--- |
| **Переменные** | `var x = 1;`<br>`let c = 2;` | `let mut x = 1;`<br>`let c = 2;` | `var x = 1;`<br>`const int c = 2;` | RustSharp использует Carbon-стиль: `var` — изменяемая, `let` — неизменяемое связывание. |
| **Индексация в цикле `for`** | `for i; item in items` | `for (i, item) in items.iter().enumerate()` | `foreach (var item in items)` | В RustSharp индекс отделяется точкой с запятой `;`. |
| **Наследование классов** | `open class Base` | Отсутствует (только `trait`) | `class Base` (открыт по умолчанию) | Классы в RustSharp закрыты (`sealed`) по умолчанию. Для наследования нужен `open`. |
| **Режимы функций** | `native fn`<br>`fn` (адаптивный)<br>`runtime fn` | Всегда строго без GC | Всегда под CLR GC | По умолчанию `fn` адаптивен: оптимизирует до RAII, а при сложности делает fallback в GC. |
| **Изменяемые ссылки** | `&var T` | `&mut T` | `ref T` | Модификатор `var` подчеркивает изменяемость целевого значения. |

## 2. Базовые типы данных

> 📖 **Спецификация:** [Глава 2. Система типов](spec/SPECIFICATION.md#2-система-типов)

Язык является статически типизированным:

```rustsharp
// Целочисленные типы
var small: i16 = 32767;
var count: int = 42;             // Псевдоним для i32
var big: long = 1_000_000_000;   // Псевдоним для i64
var b: byte = 255;               // Беззнаковый 8-битный u8

// Дробные типы
var rate: float = 3.14f;         // Одинарная точность f32
var precise: double = 2.71828;   // Двойная точность f64 (по умолчанию для дробных)

// Логический и символьный
var isReady: bool = true;
var letter: char = 'R';

// Строки (неизменяемый массив символов UTF-8)
var greeting: str = "Hello, RustSharp!";
var multiline: str = `Многострочный
текст`;

// Массивы
var numbers: int[] = [1, 2, 3, 4, 5];
```

## 3. Переменные и связывания (Carbon-стиль)

> 📖 **Спецификация:** [Глава 3. Переменные, константы и области видимости](spec/SPECIFICATION.md#3-переменные-константы-и-области-видимости)

RustSharp разграничивает изменяемые переменные, неизменяемые связывания и константы времени компиляции:

```rustsharp
// Изменяемая переменная (var)
var counter: int = 0;
counter = counter + 1; // Корректно

// Неизменяемое связывание времени выполнения (let)
let maxLimit: int = FetchLimitFromConfig();
// maxLimit = 200; // Ошибка компиляции: let нельзя повторно присваивать!

// Константа времени компиляции (const)
const PI: double = 3.1415926535;

// Автоматический вывод типа
var score = 100;          // Тип выведен как int
let message = "Success";  // Тип выведен как str
```

## 4. Управление потоком (Control Flow)

> 📖 **Спецификация:** [Глава 5. Управляющие конструкции](spec/SPECIFICATION.md#5-управляющие-конструкции)

### 4.1 Ветвления `if` / `else`
Круглые скобки вокруг условий не требуются:

```rustsharp
var score = 85;

if score >= 90 {
    Console.Println("Отлично");
} else if score >= 60 {
    Console.Println("Хорошо");
} else {
    Console.Println("Попробуйте снова");
}
```

### 4.2 Циклы `while` и `for`

```rustsharp
// Цикл while
var n = 3;
while n > 0 {
    Console.Println(n);
    n = n - 1;
}

// Цикл for по коллекции или диапазону
for item in items {
    Console.Println(item);
}

// Цикл for с индексом (через точку с запятой ;)
for index; item in items {
    Console.Println(index, item);
}
```

## 5. Функции и режимы исполнения (`native`, `runtime`, `fn`)

> 📖 **Спецификация:** [Глава 6. Функции](spec/SPECIFICATION.md#6-функции) и [Раздел 9.2 Native vs Runtime](spec/SPECIFICATION.md#92-native-vs-runtime-функции-и-нестрогий-режим-по-умолчанию)  
> 🧠 **Модель памяти:** [docks/ru/04-memory-model.md](04-memory-model.md)

### 5.1 Объявление функций и вывод результатов

```rustsharp
// Функция с параметрами и возвращаемым значением
fn Sum(a: int, b: int) -> int {
    return a + b;
}

// Процедура (возврат void)
pub fn Greet(name: str) -> void {
    Console.Println("Привет, " + name);
}
```

### 5.2 Режимы исполнения: `native`, `runtime` и нестрогий адаптивный `fn`

RustSharp даёт гибкость выбора модели исполнения:

```rustsharp
// 1. Адаптивная функция по умолчанию (Non-strict / Hybrid)
// Оптимизируется до Zero-Cost RAII, а при сложных циклических графах
// ссылок компилятор прозрачно включает GC Fallback без ошибок сборки.
fn ProcessOrder(id: int) -> str {
    var details = "Order #" + id;
    return details;
}

// 2. Строго нативная функция (Zero-Cost / Strict Native)
// Полный запрет на работу сборщика мусора и скрытые накладные расходы.
// Ошибки неразрешенных времен жизни приводят к ошибке сборки.
native fn FastCompute(val: &int) -> int {
    return *val * 2;
}

// 3. Управляемая функция (Managed / Runtime)
// Явно исполняется в среде рантайма с полной поддержкой Tracing GC и динамики.
runtime fn BuildUserInterface() -> Window {
    var win = Window();
    return win;
}
```

### 5.3 Контекстные блоки `native { ... }` и `runtime { ... }`

Внутри любой функции можно локально ограничить или расширить права среды:

```rustsharp
fn WorkerPipeline() -> void {
    native {
        // Гарантированно Zero-Cost: выделение в Managed Heap строго запрещено
        var buffer: byte[] = stackalloc byte[1024];
        buffer[0] = 0xAA;
    }

    runtime {
        // Управляемый блок: логирование, обращение к сервисам GC
        Console.Println("Низкоуровневая обработка завершена");
    }
}
```

## 6. Модель памяти в синтаксисе: ссылки (`&`), мутабельность и владение (`own`)

> 📖 **Спецификация:** [Глава 8. Модель памяти](spec/SPECIFICATION.md#8-модель-памяти)

- **`&T`** — неизменяемое заимствование (чтение).
- **`&var T`** — изменяемое заимствование (разрешена запись).
- **`*ptr`** — операция разыменования.
- **`own T`** — явная передача владения объектом.

```rustsharp
fn ReadData(val: &int) -> int {
    return *val;
}

fn Increment(val: &var int) -> void {
    *val = *val + 1;
}

native fn ConsumeResource(own res: Resource) -> void {
    // res освобождается детерминированно в конце области видимости
}
```

## 7. Объектно-ориентированное программирование (ООП)

> 📖 **Спецификация:** [Глава 7. ООП и структуры данных](spec/SPECIFICATION.md#7-ооп-и-структуры-данных)

### 7.1 Структуры (`struct`) против Классов (`class`)

* **`struct` (Значимый тип / Value Type):**
  - Размещается на стеке или непосредственно внутри другого объекта.
  - Копируется по значению при присваивании.
  - Zero runtime overhead.

```rustsharp
struct Point {
    pub var x: int;
    pub var y: int;
}

var p: Point;
p.x = 10;
p.y = 20;
```

* **`class` (Ссылочный тип / Reference Type):**
  - Размещается в куче.
  - Копируется ссылка, а не объект.
  - Управляется детерминированным деструктором (RAII) или сборщиком мусора (GC).

```rustsharp
class UserAccount {
    pub var username: str;
    var balance: double;

    pub fn Deposit(amount: double) -> void {
        balance = balance + amount;
    }
}
```

### 7.2 Модификаторы доступа и статические члены

- Члены по умолчанию приватны для класса/модуля.
- `pub` делает поле или метод доступным извне.
- `static` привязывает метод к типу, а не к экземпляру.

```rustsharp
class MathUtils {
    pub static fn Abs(x: int) -> int {
        if x < 0 {
            return -x;
        }
        return x;
    }
}

var positive = MathUtils.Abs(-15);
```

### 7.3 Наследование (`open class`) и виртуальные методы

В целях безопасности и максимальной производительности классы в RustSharp **закрыты для наследования по умолчанию**.

- Чтобы разрешить наследование, базовый класс помечается ключевым словом **`open`**.
- Методы, переопределяемые в потомках, помечаются как **`virtual`** и **`override`**.

```rustsharp
open class Entity {
    pub var id: int;

    pub virtual fn Describe() -> void {
        Console.Println("Базовая сущность");
    }
}

class Player : Entity {
    pub var nickname: str;

    pub override fn Describe() -> void {
        Console.Println("Игрок: " + nickname);
    }
}
```

## 8. Обработка ошибок и Базовый ввод-вывод

> 📖 **Спецификация:** [Глава 11. Обработка ошибок](spec/SPECIFICATION.md#11-обработка-ошибок) и [Глава 12. Стандартная библиотека](spec/SPECIFICATION.md#12-стандартная-библиотека)

```rustsharp
fn Divide(a: int, b: int) -> int {
    if b == 0 {
        panic("Деление на ноль недопустимо");
    }
    return a / b;
}

fn Main() -> void {
    Console.Println("Введите данные:");
    var input: str = Console.ReadLine();
    Console.Println("Вы ввели: " + input);
}
```
