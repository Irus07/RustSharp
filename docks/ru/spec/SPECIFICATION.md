## 1. Лексика и грамматика

### 1.1 Ключевые слова, идентификаторы, литералы

#### Идентификаторы
- **Конструкция:** `[a-zA-Z_][a-zA-Z0-9_]*`
- **Описание:** Имена переменных, констант, функций, типов и модулей начинаются с латинской буквы или символа подчеркивания, за которыми следуют буквы, цифры или подчеркивания.
- **Пример:**
```rustsharp
var counter: int = 0;
var _internal_id: i64 = 100;
```

#### Литералы
| Тип литерала | Конструкция | Описание | Пример |
| :--- | :--- | :--- | :--- |
| **Логические** | `true` \| `false` | Истинное или ложное значение типа `bool` | `var isValid: bool = true;` |
| **Целочисленные** | `[0-9]+`, разделитель `_`, знак `-` | Десятичные знаковые и беззнаковые целые числа | `var a: int = 1;`<br>`var b: int = -2;`<br>`var c: i64 = 1_000_000;` |
| **Дробные** | `[0-9]+\.[0-9]+[f]?`, разделитель `_` | Числа с плавающей точкой. По умолчанию `double` (`f64`), суффикс `f` обозначает `float` (`f32`) | `var pi: double = 3.14159;`<br>`var rate: float = 2.5f;`<br>`var bigVal: float = 10_000f;` |
| **Строковые** | `"..."` или `` `...` `` | Строки в двойных кавычках или обратных кавычках (поддержка переносов строк) | `var s1: str = "Hello, world!";`<br>``var s2: str = `Multi-line string`;`` |
| **Символьные** | `'символ'` | Одиночный символ в одинарных кавычках | `var dash: char = '-';`<br>`var letter: char = 'R';` |

---

### 1.2 Комментарии

#### Однострочный комментарий
- **Конструкция:** `// <текст комментария до конца строки>`
- **Описание:** Игнорируется компилятором от двух символов слеша до конца текущей строки.
- **Пример:**
```rustsharp
var step: int = 1; // Увеличиваем шаг итерации
```

#### Многострочный (блочный) комментарий
- **Конструкция:** `/* <текст комментария> */`
- **Описание:** Блочный комментарий может занимать одну или несколько строк.
- **Пример:**
```rustsharp
/*
  Данный блок кода отвечает
  за инициализацию подсистемы
*/
var ready: bool = true;
```

## 2. Система типов

### 2.1 Примитивные типы

| Категория | Конструкция (Тип) | Альтернативный псевдоним | Размер | Описание | Пример |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Логический** | `bool` | — | 1 байт | Значения `true` или `false` | `var flag: bool = true;` |
| **Целочисленные** | `i16` | — | 16 бит | 16-битное целое со знаком | `var s: i16 = 32767;` |
| | `int` | `i32` | 32 бита | 32-битное целое со знаком | `var x: int = 42;`<br>`var y: i32 = 42;` |
| | `long` | `i64` | 64 бита | 64-битное целое со знаком | `var big: long = 9_000_000_000;` |
| | `byte` | `u8` | 8 бит | Беззнаковый 8-битный байт | `var b: byte = 255;` |
| **Дробные** | `f16` | — | 16 бит | Половинная точность (half precision) | `var h: f16 = 1.0;` |
| | `float` | `f32` | 32 бита | Одинарная точность IEEE 754 | `var val: float = 3.14f;` |
| | `double` | `f64` | 64 бита | Двойная точность IEEE 754 | `var d: double = 1.41421356;` |
| **Символьный** | `char` | — | 1–4 байта | Символ UTF-8 / UTF-32 | `var ch: char = 'A';` |

---

### 2.2 Составные типы

#### Строковый тип (`str`)
- **Конструкция:** `str` (внутреннее представление: непрерывный массив символов `char[]`)
- **Описание:** Текстовые неизменяемые строки символов. Обеспечивают высокую скорость работы и совместимость с массивами символов.
- **Пример:**
```rustsharp
var greeting: str = "RustSharp Language";
```

#### Массивы
- **Конструкция:** `<тип>[]`
- **Описание:** Упорядоченная последовательность элементов фиксированного или динамического размера одного типа.
- **Пример:**
```rustsharp
var numbers: int[] = [1, 2, 3, 4, 5];
```

---

### 2.3 Вывод типов (Type Inference)

#### Неявный вывод типа
- **Конструкция:** `var <имя_переменной> = <выражение>;`
- **Описание:** Если тип переменной не указан явно через двоеточие, компилятор RustSharp автоматически вычисляет и фиксирует тип на основе правого выражения на этапе компиляции.
- **Пример:**
```rustsharp
var inferredInt = 10;           // Тип выведен как int (i32)
var inferredFloat = 3.14f;      // Тип выведен как float (f32)
var inferredStr = "Auto type";  // Тип выведен как str
```

## 3. Переменные, константы и области видимости

### 3.1 Объявление переменных (Carbon-стиль)

#### Изменяемая переменная с инициализатором
- **Конструкция:** `var <имя>: <тип> = <значение>;`
- **Описание:** Создает мутабельную (изменяемую) переменную указанного типа с начальным значением.
- **Пример:**
```rustsharp
var count: int = 0;
count = count + 1; // Корректно: переменная изменяема
```

#### Изменяемая переменная без инициализатора
- **Конструкция:** `var <имя>: <тип>;`
- **Описание:** Объявляет переменную с типом по умолчанию без немедленного присваивания (инициализируется значением по умолчанию перед первым чтением).
- **Пример:**
```rustsharp
var name: str;
name = "RustSharp";
```

---

### 3.2 Константы и неизменяемые связывания

#### Неизменяемое связывание (`let`)
- **Конструкция:** `let <имя>: <тип> = <значение>;`
- **Описание:** Объявляет неизменяемое значение. Повторное присваивание вызывает ошибку компиляции. Константа обязана быть инициализирована при определении.
- **Пример:**
```rustsharp
let maxUsers: int = 100;
// maxUsers = 200; // Ошибка компиляции: переменная объявлена через let и неизменяема
```

#### Константа времени компиляции (`const`)
- **Конструкция:** `const <имя>: <тип> = <константное_выражение>;`
- **Описание:** Символическая константа, значение которой полностью вычисляется на этапе сборки.
- **Пример:**
```rustsharp
const appTitle: str = "Hello world";
const bufferSize: int = 1024 * 4;
```

---

### 3.3 Области видимости (Scope)

- **Конструкция:** `{ <тело блока> }`
- **Описание:** Локальные переменные видимы только внутри текущего блока кода `{ ... }` и всех вложенных в него подблоков. При выходе из блока область видимости переменной завершается.
- **Пример:**
```rustsharp
fn Main() { 
    var x: int = 12;
    { 
        var y: int = x; // Ok: x доступен во вложенном блоке
    } 
    var z: int = x;     // Ok: x доступен в текущем блоке
    // var v: int = y;  // Ошибка компиляции: y недоступен за пределами внутреннего блока
}
```

## 4. Выражения и операторы

### 4.1 Арифметические операторы

| Операция | Конструкция | Описание | Пример |
| :--- | :--- | :--- | :--- |
| **Сложение** | `a + b` | Возвращает сумму двух операндов | `var res: int = 10 + 5;` |
| **Вычитание** | `a - b` | Возвращает разность операндов | `var res: int = 10 - 3;` |
| **Умножение** | `a * b` | Возвращает произведение операндов | `var res: int = 4 * 7;` |
| **Деление** | `a / b` | Целочисленное или вещественное деление | `var res: double = 10.0 / 4.0;` |
| **Остаток от деления** | `a % b` | Возвращает остаток от деления первого операнда на второй | `var rem: int = 10 % 3; // 1` |
| **Возведение в степень** | `a ** b` | Возводит `a` в степень `b` | `var sq: int = 2 ** 8; // 256` |
| **Инкремент** | `a++` / `++a` | Увеличивает переменную на 1 | `var i: int = 0; i++;` |
| **Декремент** | `a--` / `--a` | Уменьшает переменную на 1 | `var i: int = 10; i--;` |

---

### 4.2 Приоритеты и ассоциативность

Приоритеты соответствуют стандартной математической и общепринятой иерархии языков (C/Rust):
1. Скобки `(...)`, доступ к членам `.`, вызовы функций `()`.
2. Постфиксные и унарные операторы: `++`, `--`, `!`, унарный минус `-`.
3. Возведение в степень: `**` (правоассоциативный).
4. Мультипликативные операторы: `*`, `/`, `%`.
5. Аддитивные операторы: `+`, `-`.
6. Операторы сравнения: `<`, `<=`, `>`, `>=`.
7. Операторы равенства: `==`, `!=`.
8. Логическое И: `&&`.
9. Логическое ИЛИ: `||`.
10. Присваивание и перемещение: `=`, `own`.

---

### 4.3 Сравнения, логика, копирование и перемещение (own)

#### Операторы сравнения и равенства
- **Конструкция:** `==`, `!=`, `<`, `<=`, `>`, `>=`
- **Описание:** Сравнивают два значения и возвращают `bool`.
- **Пример:**
```rustsharp
var isGreater: bool = (5 > 3); // true
var isEqual: bool = (x == y);
```

#### Логические операторы
- **Конструкция:**
  - `&&` — логическое И (короткое замыкание)
  - `||` — логическое ИЛИ (короткое замыкание)
  - `!` — логическое отрицание (НЕ)
- **Описание:** Булевы операции над операндами типа `bool`.
- **Пример:**
```rustsharp
var canProceed: bool = (userAge >= 18) && hasLicense;
var alert: bool = !isValid;
```

#### Присваивание (копирование)
- **Конструкция:** `<переменная> = <выражение>;`
- **Описание:** Для значимых типов (value types) копирует бинарное представление данных.
- **Пример:**
```rustsharp
var a: int = 10;
var b: int = a; // Значение a скопировано в b
```

#### Перемещение владения (`own`)
- **Конструкция:** `var <новое_имя>: <тип> = own <исходное_имя>;`
- **Описание:** Семантика явного перемещения (Move semantics) в стиле Rust: передает полное право владения объектом новой переменной, делая исходную переменную недействительной для дальнейшего чтения компилятором.
- **Пример:**
```rustsharp
var originalBuffer: str = "Данные ресурса";
var newOwner: str = own originalBuffer; // originalBuffer перемещен
// Использование originalBuffer после own вызовет ошибку компиляции!
```

## 5. Управляющие конструкции

### 5.1 Условные переходы if / else

- **Конструкция:**
```rustsharp
if <условие> {
    <блок_then>
} else if <условие_2> {
    <блок_elif>
} else {
    <блок_else>
}
```
- **Описание:** Выполняет блок кода при соблюдении булева условия. Круглые скобки вокруг условия не обязательны. Ветки `else if` и `else` являются опциональными.
- **Пример:**
```rustsharp
var score: int = 85;

if score >= 90 {
    // Высокий балл
} else if score >= 60 {
    // Удовлетворительный результат
} else {
    // Требуется пересдача
}
```

---

### 5.2 Циклы while и for

#### Цикл с предусловием (`while`)
- **Конструкция:**
```rustsharp
while <условие> {
    <тело_цикла>
}
```
- **Описание:** Повторяет блок инструкций до тех пор, пока булево условие истинно.
- **Пример:**
```rustsharp
var counter: int = 3;
while counter > 0 {
    counter--;
}

// Бесконечный цикл:
while true {
    break;
}
```

#### Классический трехсекционный цикл (`for`)
- **Конструкция:**
```rustsharp
for <инициализация>; <условие>; <шаг> {
    <тело_цикла>
}
```
- **Описание:** Классический цикл со счетчиком. В секции инициализации переменная объявляется в Carbon-стиле `var i: int = 0`.
- **Пример:**
```rustsharp
for var i: int = 0; i < 10; i++ {
    // Итерация от 0 до 9
}
```

#### Цикл итерации по коллекции (foreach)
- **Конструкция 1 (только элемент):**
```rustsharp
for <элемент> in <коллекция> {
    <тело_цикла>
}
```
- **Конструкция 2 (с индексом элемента):**
```rustsharp
for <индекс>; <элемент> in <коллекция> {
    <тело_цикла>
}
```
- **Описание:** Последовательно обходит каждый элемент коллекции. При необходимости индекс текущего элемента указывается перед точкой с запятой.
- **Пример:**
```rustsharp
var items: int[] = [10, 20, 30];

// Обход элементов:
for item in items {
    // Использование item
}

// Обход с получением индекса:
for index; item in items {
    // index — текущий порядковый номер, item — значение
}
```

## 6. Функции

### 6.1 Объявление, параметры и возврат значения

- **Конструкция:**
```rustsharp
[модификатор] fn <имя_функции>([<параметр1>: <тип1>, ...]) -> <тип_возврата> {
    <тело_функции>
    return <значение>;
}
```
- **Описание:** Функция объявляется ключевым словом `fn`. Параметры указываются в формате Carbon/Rust (`имя: тип`). Если функция ничего не возвращает, указывается `-> void` либо возвращаемый тип опускается. Модификатор `pub` делает функцию доступной вне модуля.
- **Пример:**
```rustsharp
// Процедура без возвращаемого значения:
pub fn Foo() -> void {
    // Логика функции
}

// Функция с аргументами и возвращаемым значением:
fn Add(a: int, b: int) -> int {
    return a + b;
}
```

---

### 6.2 Рекурсия

- **Конструкция:** Вызов функции самой себя внутри собственного тела с граничным условием выхода.
- **Описание:** RustSharp поддерживает прямую рекурсию со стандартным размещением стековых кадров.
- **Пример (Вычисление факториала):**
```rustsharp
fn Fact(num: int) -> int { 
    if num == 0 { 
        return 1;
    } else if num == 1 { 
        return 1;
    } else { 
        return num * Fact(num - 1);
    } 
}
```

---

### 6.3 Перегрузка функций

- **Конструкция:** Определение нескольких функций с одинаковым идентификатором, но различающимся набором или типами параметров.
- **Описание:** Компилятор сопоставляет вызов на этапе компиляции по сигнатуре аргументов.
- **Пример:**
```rustsharp
fn PrintValue(val: int) -> void {
    // Вывод целого числа
}

fn PrintValue(val: str) -> void {
    // Вывод строки
}
```

### 6.4 Режимы исполнения: native, runtime и адаптивный fn

- **Конструкция:**
```rustsharp
// Нестрогий (адаптивный) режим по умолчанию
fn <имя>(<параметры>) -> <тип> { ... }

// Строгий нативный режим (Zero-Cost / Strict)
native fn <имя>(<параметры>) -> <тип> { ... }

// Управляемый режим (Managed / GC)
runtime fn <имя>(<параметры>) -> <тип> { ... }
```
- **Описание:**
  - `fn` (по умолчанию) — адаптивная нестрогая функция. Компилятор пытается оптимизировать память через статический RAII анализ, а при невозможности однозначного доказательства времен жизни прозрачно включает GC Fallback без ошибок сборки.
  - `native fn` — строгий нативный контракт. Запрещены GC-аллокации и скрытые накладные расходы рантайма. Ошибки borrow checker приводят к ошибкам компиляции.
  - `runtime fn` — функция, выполняющаяся в управляемой среде с полной поддержкой Tracing GC, классов и динамического полиморфизма.
- **Пример:**
```rustsharp
native fn VectorDot(a: &Vector3, b: &Vector3) -> float {
    return a.x * b.x + a.y * b.y + a.z * b.z;
}

runtime fn LoadConfig(path: str) -> AppConfig {
    return AppConfig.ParseJson(path);
}
```

---

### 6.5 Контекстные блоки native и runtime

- **Конструкция:**
```rustsharp
native {
    <инструкции_без_gc>
}

runtime {
    <управляемые_инструкции>
}
```
- **Описание:** Локальные блоки для точечного задания режима исполнения внутри функций любого типа. Внутри `native { ... }` запрещено неявное выделение памяти в Managed Heap. Внутри `runtime { ... }` разрешён доступ к службам рантайма и сборщика мусора.
- **Пример:**
```rustsharp
fn MixedTask() -> void {
    native {
        var raw_bytes: byte[] = stackalloc byte[128];
        raw_bytes[0] = 0xFF;
    }

    runtime {
        Console.Println("Нативная обработка буфера завершена");
    }
}
```

## 7. ООП и структуры данных

### 7.1 Структуры (`struct`)
- **Конструкция:**
```rustsharp
struct <ИмяСтруктуры> {
    var <поле>: <тип>;
}
```
- **Описание:** Значимый тип данных (Value Type). Аллоцируется на стеке или в составе объемлющего объекта. Копируется по значению при присваивании.
- **Пример:**
```rustsharp
struct Point {
    var x: int;
    var y: int;
}

var p: Point;
p.x = 10;
p.y = 20;
```

---

### 7.2 Классы (`class`)
- **Конструкция:**
```rustsharp
class <ИмяКласса> {
    var <поле>: <тип>;
    fn <Метод>() -> <тип> { ... }
}
```
- **Описание:** Ссылочный тип данных (Reference Type). Аллоцируется в управляемой куче (Heap), время жизни контролируется статической моделью владения или средой исполнения (Runtime/GC).
- **Пример:**
```rustsharp
class UserAccount {
    pub var username: str;
    var balance: double;

    pub fn Deposit(amount: double) -> void {
        balance = balance + amount;
    }
}
```

---

### 7.3 Поля, методы и модификаторы доступа
- **Конструкция:**
  - `pub` — публичный доступ (доступен снаружи класса и модуля)
  - По умолчанию (без `pub`) — приватный доступ внутри класса/модуля
- **Описание:** Защита инкапсулированных данных.
- **Пример:**
```rustsharp
class Engine {
    pub var power: int;
    var serialNumber: str; // Приватное поле
}
```

---

### 7.4 Статические члены
- **Конструкция:**
```rustsharp
class <Имя> {
    static fn <ИмяФункции>() -> <тип> { ... }
}
```
- **Описание:** Статические методы привязаны к типу, а не к конкретному экземпляру.
- **Пример:**
```rustsharp
class MathHelper {
    pub static fn Abs(x: int) -> int {
        if x < 0 {
            return -x;
        }
        return x;
    }
}

var val: int = MathHelper.Abs(-42);
```

---

### 7.5 Наследование и спецификатор `open`
- **Конструкция:**
```rustsharp
open class <БазовыйКласс> { ... }
class <ПроизводныйКласс> : <БазовыйКласс> { ... }
```
- **Описание:** По умолчанию классы закрыты для наследования (sealed). Спецификатор `open` разрешает наследование от данного класса.
- **Пример:**
```rustsharp
open class Shape {
    pub var name: str;
}

class Circle : Shape {
    pub var radius: double;
}
```

---

### 7.6 Виртуальные методы и динамическая диспетчеризация
- **Конструкция:**
```rustsharp
open class Base {
    pub virtual fn Draw() -> void { ... }
}

class Derived : Base {
    pub override fn Draw() -> void { ... }
}
```
- **Описание:** Ключевые слова `virtual` и `override` определяют поведение полиморфных вызовов через таблицу виртуальных методов (vtable).
- **Пример:**
```rustsharp
open class Greeter {
    pub virtual fn Greet() -> void {
        // Базовое приветствие
    }
}

class CustomGreeter : Greeter {
    pub override fn Greet() -> void {
        // Кастомное приветствие
    }
}
```

## 8. Модель памяти

### 8.1 Сегменты памяти: static, stack, heap
- **Конструкция:** Архитектурная модель разделения памяти на уровне компилятора:
- **Описание:**
  - **Static (Статическая память):** Глобальные константы, литералы строк и статические таблицы. Доступны на протяжении всей работы программы.
  - **Stack (Стек):** Локальные переменные примитивных типов (`int`, `bool`, `float`), адреса возврата функций, структуры (`struct`). Очень быстрое выделение и автоматическое освобождение при выходе из скоупа.
  - **Heap (Куча):** Динамические объекты, экземпляры `class`, динамические срезы коллекций.
- **Пример:**
```rustsharp
fn Example() -> void {
    var stackVal: int = 42;             // Stack
    var point: Point;                   // Stack (struct)
    var account: UserAccount = UserAccount(); // Heap (class)
}
```

---

### 8.2 Указатели и ссылки
- **Конструкция:**
  - Ссылка на значение: `&`
  - Разыменование: `*`
  - Передача владения: `own`
- **Описание:** Позволяет передавать структуры и объекты без копирования данных с контролем безопасного доступа.
- **Пример:**
```rustsharp
fn UpdateScore(scoreRef: &var int) -> void {
    *scoreRef = *scoreRef + 10;
}
```

## 9. Среда исполнения (Runtime)

### 9.1 Роль Runtime в RustSharp
- **Описание:**
  RustSharp сочетает высокую производительность машинного кода (LLVM) и гибкость рантайма:
  1. **Статический анализ (Zero-Cost / Ownership):** Если компилятор способен однозначно доказать время жизни объекта, он детерминированно освобождает его при выходе из области видимости.
  2. **Runtime Fallback:** Если граф ссылок сложен (циклические ссылки, разделяемое владение), объект регистрируется в подсистеме Runtime, которая следит за памятью и предотвращает утечки.

---

### 9.2 Native vs Runtime функции (и нестрогий режим по умолчанию)

Подробное руководство по модели памяти см. в документе: 👉 **[Модель памяти RustSharp](../04-memory-model.md)**

| Режим функции | Конструкция | Описание | Пример |
| :--- | :--- | :--- | :--- |
| **Native (Strict Zero-Cost)** | `native fn <имя>() -> <тип>` | Полностью детерминированный код без рантайм-накладных расходов (Zero-Cost). Запрещены вызовы сборщика мусора и неявные аллокации. Ошибки borrow checker приводят к ошибке сборки. Компилируется в чистый zero-overhead LLVM IR. | `native fn Compute(a: int) -> int { return a * 2; }` |
| **Hybrid (Default / Non-strict)** | `fn <имя>() -> <тип>` | Нестрогий адаптивный режим. Статический анализ RAII при возможности, автоматический fallback в рантайм (GC) без ошибок компиляции при сложном графе ссылок. | `fn ProcessOrder(id: int) -> Order { ... }` |
| **Runtime (Explicit Managed)** | `runtime fn <имя>() -> <тип>` | Функция с явным исполнением в управляемой среде (Managed Heap, GC, полиморфизм, события). | `runtime fn ProcessUser(id: int) -> UserAccount { ... }` |

## 11. Обработка ошибок

- **Конструкция:** Возврат обобщенных результатов либо сигналы прерывания.
- **Описание:** Поддержка явного распространения ошибок без неконтролируемых сбоев.
- **Пример:**
```rustsharp
fn Divide(a: int, b: int) -> int {
    if b == 0 {
        // Сигнал об ошибке деления на ноль
        panic("Division by zero");
    }
    return a / b;
}
```
